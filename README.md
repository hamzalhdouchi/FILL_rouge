# 🍽️ Application Web de Services pour la Restauration

## 📌 Présentation du Projet

Ce projet a été réalisé dans le cadre de la 1ère année de formation en **Développement Web**, dans le cadre du **Projet Fil Rouge**.

L’objectif est de concevoir une **plateforme digitale complète** pour la gestion des services en restaurant : commandes à table, paiements avancés, livraisons, réservations, etc. Cette solution moderne vise à optimiser l’expérience client tout en facilitant la gestion interne du restaurant.

## 🎯 Objectifs Principaux

- Digitaliser l’expérience client en salle
- Optimiser les commandes et les paiements
- Intégrer un service de livraison efficace
- Renforcer la transparence client
- Permettre la réservation avec précommande

---

## 🔧 Fonctionnalités Clés

- 🧾 **Commandes par table avec QR code** et suivi temps réel
- 💳 **Paiements avancés** (en ligne, différé, partagé)
- 🛵 **Livraison à domicile** avec tracking en temps réel
- 📆 **Réservation de table** avec option de précommande
- 📡 **Mode hors-ligne** (future amélioration)
- 📦 **Gestion avancée des livreurs** (future amélioration)

---

## 🛠️ Stack Technique

### Frontend
- **Langages :** HTML, CSS, JavaScript
- **Framework :** React.js
- **Caractéristiques :** Responsive, SPA, interaction API REST

### Backend
- **Langage :** PHP (v10)
- **API REST** sécurisée via **Sanctum**
- **Modules :** Commandes, Paiements, Utilisateurs...

### Base de Données
- **SGBD :** PostgreSQL
- **Sauvegardes automatiques**, indexation pour performance

### Paiement
- **Intégré avec :** PayPal
- **Factures électroniques**, transactions sécurisées
